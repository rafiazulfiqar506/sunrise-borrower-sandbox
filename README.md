# Sunrise Microfinance — Borrower Management Sandbox

A Docker-based staging sandbox: a simple Express web app (login +
borrower list) backed by PostgreSQL, populated with 500+ synthetic
borrower records for security testing practice. All data is fake —
see `docs/Scope_Authorization.pdf` for the authorized scope.

## What's in this repo
```
Dockerfile              # builds the web app image
docker-compose.yml       # orchestrates db + seed + app
src/server.js             # Express app: /login, /borrowers
scripts/schema.sql        # Postgres table definition
scripts/generate_borrowers.py   # generates 500+ synthetic records
scripts/Dockerfile.seed   # builds the one-shot seeding container
docs/Scope_Authorization.pdf    # signed scope/authorization document
```

## Prerequisites
- Docker + Docker Compose installed and running

## Build and run (under 10 minutes)

1. Clone this repository and move into it:
   ```
   git clone <this-repo-url>
   cd sunrise-sandbox
   ```

2. Build and start everything:
   ```
   docker compose up -d --build
   ```
   This starts PostgreSQL, waits for it to be healthy, runs the
   one-shot seeding job (inserts 500 synthetic borrower records), and
   starts the web app — all automatically.

3. Wait about 30-60 seconds for the seed job to finish (first run only;
   Postgres image pull + npm install can take a few minutes on a slow
   connection). Check progress with:
   ```
   docker compose logs seed
   ```
   You should see: `Inserted 500 synthetic borrower records into the database.`

4. Open your browser to:
   ```
   http://localhost:8000
   ```
   You'll be redirected to a login page.

5. Log in with the demo credentials:
   - **Username:** `admin`
   - **Password:** `admin123`

6. You'll see a table of synthetic borrower records (first 100 of 500+).

## Resetting the sandbox to a clean state

To fully reset (wipe the database and reseed from scratch):
```
docker compose down -v
docker compose up -d --build
```
The `-v` flag removes the database volume, so the next `up` starts with
an empty database and the seed job repopulates it fresh.

To just restart the app/db without wiping data:
```
docker compose restart
```

## Stopping the sandbox
```
docker compose down
```

## Notes
- This is a deliberately simple app built for security-testing practice
  — it is not intended as a production reference for secure coding
  (e.g. the demo login credential is intentionally simple and documented
  here, not something to replicate in a real system).
- All borrower names, mock national IDs, mock bank account numbers, and
  loan balances are randomly generated by `scripts/generate_borrowers.py`
  — none of this data represents a real person or real financial record.
